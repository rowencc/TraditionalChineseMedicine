# 倪海厦中医小程序

> 基于倪海厦（1954-2012）中医知识库开发的跨平台小程序，收录伤寒论129条、金匮23篇、黄帝内经71篇、神农本草经345种药物、849个临床医案。

## 项目简介

本项目将倪海厦先生的中医知识体系数字化，提供方剂查询、药物检索、医案浏览、针灸穴位、六经辨证等功能，帮助中医学习者快速查阅和学习。

### 数据来源

| 讲义 | 页数 | 内容 |
|------|------|------|
| 伤寒论讲义 | 209页 | 129条原文解读 |
| 金匮要略讲义 | 419页 | 23篇杂病论治 |
| 黄帝内经讲义 | 461页 | 71篇基础理论 |
| 针灸教程讲义 | 216页 | 十二经络穴位 |
| 神农本草经文稿 | 339页 | 345种药物性味 |

## 功能模块

### 1. 方剂速查（92首）

按六经分类的经方数据库，包含：
- 太阳病篇：23首（桂枝汤、麻黄汤、小青龙汤等）
- 阳明病篇：21首（白虎汤、承气汤、栀子豉汤等）
- 少阳病篇：11首（小柴胡汤、大柴胡汤等）
- 太阴病篇：6首（理中汤、建中汤等）
- 少阴病篇：25首（四逆汤、真武汤等）
- 厥阴病篇：6首（乌梅丸、当归四逆汤等）

### 2. 药物查询（349味）

神农本草经完整收录：
- 上经：120味（补益类，久服轻身延年）
- 中经：91味（治病类，毒药治病）
- 下经：138味（攻毒类，不可久服）

每味药物包含：性味、归经、功效、用量、禁忌

### 3. 医案浏览（188例）

倪海厦临床医案精选，按疾病分类：
- 癌症：148例（肝癌、肺癌、乳癌、血癌等）
- 心血管：22例（心脏病、高血压、中风等）
- 代谢病：12例（糖尿病、肾衰竭等）
- 自身免疫：2例（类风湿、红斑狼疮）
- 神经精神：3例（癫痫、帕金森等）
- 其他：59例

### 4. 针灸穴位（309个）

十二经络完整穴位：
- 手太阴肺经：11穴
- 手阳明大肠经：20穴
- 足阳明胃经：45穴
- 足太阴脾经：21穴
- 手少阴心经：9穴
- 手太阳小肠经：19穴
- 足太阳膀胱经：67穴
- 足少阴肾经：27穴
- 手厥阴心包经：9穴
- 手少阳三焦经：23穴
- 足少阳胆经：44穴
- 足厥阴肝经：14穴

### 5. 六经辨证

交互式辨证辅助：
- 输入症状自动推荐六经归属
- 展示对应方剂和条文
- 八纲辨证分析

## 技术栈

- **框架**：uni-app（Vue 3 + TypeScript）
- **构建**：Vite 5.x
- **样式**：SCSS
- **数据**：本地 JSON 文件
- **平台**：微信小程序 / H5 / 支付宝小程序

## 快速开始

### 环境要求

- Node.js >= 16
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发

```bash
# H5 开发
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin
```

### 构建发布

```bash
# 构建 H5
npm run build:h5

# 构建微信小程序
npm run build:mp-weixin
```

## 使用示例

### 方剂查询
```
搜索"桂枝" → 显示桂枝汤、桂枝加葛根汤等
点击进入详情 → 查看组成、剂量、主治、出处
```

### 药物查询
```
按性味筛选"温" → 显示所有温性药物
点击查看详情 → 性味归经、功效用量
```

### 医案浏览
```
按分类筛选"癌症" → 显示147个癌症医案
治疗方剂红色高亮显示
```

### 针灸穴位
```
选择经络 → 展开穴位列表
点击穴位 → 定位方法、主治、配穴
```

## 数据来源说明

本项目数据来源于：
- 倪海厦人纪系列讲义
- 《神农本草经》原文
- 《伤寒论》《金匮要略》原文
- 倪海厦临床医案集

数据仅供中医学习参考，不替代专业医疗诊断。
