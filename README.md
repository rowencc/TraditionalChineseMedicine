# 岐黄小识

> 经方中医学习工具 - 基于倪海厦中医知识体系

**岐黄**取自岐伯与黄帝，为中医代称；**小识**意为学习笔记，谦逊而有学术气质。

## 项目简介

本项目将倪海厦先生的中医知识体系数字化，提供方剂查询、药物检索、医案浏览、针灸穴位、六经辨证等功能，帮助中医学习者快速查阅和学习。

### 设计理念

- **实用性优先** - 功能清晰，操作便捷
- **传统元素点缀** - 云纹、水墨、经卷感，但不喧宾夺主
- **留白呼吸** - 大量留白，信息层次清晰
- **温润质感** - 宣纸色背景，如翻阅古籍

### 数据来源

| 讲义 | 页数 | 内容 |
|------|------|------|
| 伤寒论讲义 | 209页 | 129条原文解读 |
| 金匮要略讲义 | 419页 | 23篇杂病论治 |
| 黄帝内经讲义 | 461页 | 71篇基础理论 |
| 针灸教程讲义 | 216页 | 十二经络穴位 |
| 神农本草经文稿 | 339页 | 345种药物性味 |

## 功能模块

### 1. 方剂速查（92首）

按六经分类的经方数据库：
- 太阳病篇：23首（桂枝汤、麻黄汤、小青龙汤等）
- 阳明病篇：21首（白虎汤、承气汤、栀子豉汤等）
- 少阳病篇：11首（小柴胡汤、大柴胡汤等）
- 太阴病篇：6首（理中汤、建中汤等）
- 少阴病篇：25首（四逆汤、真武汤等）
- 厥阴病篇：6首（乌梅丸、当归四逆汤等）

### 2. 药物查询（349味）

神农本草经完整收录：
- 上经：120味（补益类，久服轻身延年）
- 中经：91味（治病类，毒药治病）
- 下经：138味（攻毒类，不可久服）

### 3. 医案浏览（188例）

倪海厦临床医案精选，按疾病分类：
- 癌症：148例
- 心血管：22例
- 代谢病：12例
- 自身免疫：2例
- 神经精神：3例
- 其他：59例

### 4. 针灸穴位（309个）

十二经络完整穴位，包含定位方法、主治病症、常用配穴。

### 5. 六经辨证

交互式辨证辅助，输入症状自动推荐六经归属和对应方剂。

## 技术栈

### 前端
- **框架**：uni-app（Vue 3 + TypeScript）
- **构建**：Vite 5.x
- **样式**：SCSS
- **平台**：微信小程序 / H5 / 支付宝小程序

### 后端
- **框架**：FastAdmin（ThinkPHP 5.x）
- **数据库**：MySQL 5.7+
- **插件**：岐黄小识中医知识库插件

### AI 问诊
- **接口**：RESTful API
- **算法**：六经辨证规则引擎
- **扩展**：支持接入大模型 API
